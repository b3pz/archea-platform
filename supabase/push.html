Notifiche vere · Edge Function push

Serve una volta sola, dopo aver eseguito SETUP_COMPLETO.sql. Fa arrivare le notifiche su computer e telefono anche a sito chiuso.

  1. Premi Copia tutto.
  2. Apri Supabase → Edge Functions → Deploy a new function → Via Editor.
  3. Nome della funzione: push. Cancella il testo di esempio, incolla e premi Deploy function.
  4. Nella pagina della funzione apri Details e disattiva «Verify JWT» (Enforce JWT Verification), poi Save.
  5. Entra nel sito come Super admin e premi Attiva le notifiche in Inizio: le chiavi si creano da sole.
