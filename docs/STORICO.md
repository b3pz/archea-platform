# Storico delle versioni precedenti

Le note originali delle singole release sono nella cronologia Git di questa repository e delle repository di provenienza.

## Service Desk IT (b3pz/Archea_IT)
- **V1.x**: ticket, ruoli USER/IT/SUPER_IT, notifiche interne, appuntamenti con conferma, Telegram solo alla creazione del ticket.
- **V2–V4**: coda IT con filtri e ricerca, presa in carico, collaboratori, checklist, prenotazione materiale.
- **V5**: censimento dispositivi (import Device), movimenti HR, restyle.
- **V6**: anagrafica persone unificata, valori controllati, conflitti dati.
- **V7**: interfaccia mobile first.
- **V8**: mappa postazioni e magazzino, fotocamera/scanner, export Excel, HR amministratore, scanner per iPhone.

- **0.6–0.14**: desktop app, contabilità e Property, organico, cantiere, calendario, prenotazioni, reparti Interior/Concept/Visual, materioteca, fornitori, pianificazione, ARCHEAI (tutto con dati dimostrativi).
